# MedEssay
It is a Web based study tool for medical students that helps to practice essay styled questions across core subjects namely Anatomy, Physiology and Biochemistry.

## Live Demo
https://medessay.netlify.app

## What It Does
Medical study tools mostly focus on MCQs and objectives. MedEssay on the other hand fills that gap by providing students with open-ended essay questions the way they appear in real-life exams, giving students an opportunity to practice structuring and writing full answers rather than just merely selecting options.

## Features
- Essay questions organized by subject and topic
- Covers the following topics: Anatomy, Physiology, and Biochemistry (for now)
- Features a feedback form for users to report issues and or suggest improvements
- Has a clean, distraction free UI/UX built intentionally for focused study
